# PSD2Live

[中文](../../README.md) · [English](../en/README.md) · [ダウンロード](https://github.com/tsunehimatoi/psd2live/releases/latest) · [ドキュメント](../README.md)

**レイヤー付き PSD から Live2D モデルを自動生成し、調整・リギング・アニメーション・物理・書き出しまでを一つのデスクトップ画面で行います。**

![PSD2Live の編集画面：左に階層ツリー、中央のキャンバスは変形モードで前髪のメッシュを表示、右にモデルプリセットとレイヤー分類表](../imgs/overview.webp)

PSD2Live はレイヤー名からパーツを判定し、メッシュ、デフォーマ階層、頭・体・顔のパラメータ、基本モーション、物理を生成します。生成結果は出発点です。キャンバスで形を整え、メッシュを切断・細分化し、テクスチャを描き、ボーンを組み、モーションカーブを編集したうえで、Cubism Editor で続きの作業ができる `.cmo3`、またはランタイム用の `.moc3` 一式として書き出せます。

![同じモデルを頭と体の角度を変えて表示：左、右下、正面、右上、左下](../imgs/poses.webp)

<sub>付属のサンプル PSD を読み込んだだけの自動生成結果です。頭と体の角度パラメータで動かしています。</sub>

## 主な機能

| 分野 | 内容 |
| --- | --- |
| 自動生成 | 中国語 / 英語 / 日本語のレイヤー名判定、左右パーツの自動分割、適応メッシュ、頭と体のデフォーマチェーン、目・口・視線・眉のパラメータ、待機 / まばたき / うなずき / 首振りのモーション、髪と目の揺れ物理 |
| キャンバス編集 | 選択 / 変形 / 編集 / 描画の 4 モード。変形ブラシ、メッシュの細分化と切断、Warp / Rotation の作成、Glue、変形パス（実験的） |
| ボーン | 手足・尻尾・翼のボーンを自動推定し FK / IK でポーズ付け。書き出し時に Cubism ネイティブのデフォーマ、パラメータ、補正キーフォームへ焼き込み、PSD2Live なしで動作 |
| 揺れと物理 | 左右 / 上下の揺れを自動生成し、対応する振り子も作成。振り子の視覚的な編集、応答カーブ、連鎖物理。演算は Cubism Native Framework に合わせています |
| 素材と差分 | 透過画像の配置、表示切替差分と択一差分、レイヤー描画と縁の補修、任意の 2× / 4× テクスチャ高解像度化 |
| アニメーション | タイムライン、キーフレーム、カーブ編集とリアルタイムプレビュー。ボーンがある場合はしゃがみ・手振り・喜びなどのプリセットモーションを追加 |
| プロジェクト | 単一ファイルの `.psd2live`、分岐履歴、タブ、編集 / メッシュ / リギング / アニメーション / プレビュー / 物理演算の 6 種のワークスペースプリセット、明暗テーマ、Photoshop / Blender / Cubism 風キー設定 |
| Agent | 認証付きローカル MCP サーバー。観察、形状、素材、パラメータ、骨格、モーション、物理、シミュレーション、書き出し、履歴を扱う 170 の公開ツール（`workspace_list_operations` でページごとに取得） |

## ダウンロード

最新版は [Releases](https://github.com/tsunehimatoi/psd2live/releases/latest) から入手できます。

| プラットフォーム | パッケージ | 備考 |
| --- | --- | --- |
| Windows 10 / 11 x64 | ポータブル ZIP、EXE、MSI | Java ランタイム同梱。展開またはインストールしてすぐ起動できます |
| Linux x86_64 | Deb | ランタイムと Cubism ネイティブプレビューを同梱。X11 / GLX が必要（XWayland 可） |
| その他 | ソースから実行 | JDK 21 が必要。[ソースからのビルド](#ソースからのビルド)を参照 |

Linux のネイティブプレビューは、XWayland のない Wayland、aarch64、musl（Alpine など）には対応していません。その場合は内蔵レンダラーに自動で切り替わります。詳しくは [Cubism ネイティブプレビュー](guide/CUBISM_SDK_SETUP.md)を参照してください。

## はじめに

1. **PSD を読み込む**：**ファイル → インポート → PSD から新規プロジェクト…**（`Ctrl+Shift+O`）、またはウィンドウへドラッグします。続いて「スタート」画面が開きます。「最小 / 標準 / フル」のクイック設定でモデルプリセットを決め（標準はゆったりした衣装のシミュレーションを含みます）、離れたパーツ（左右の脚など）を含むレイヤーのうちメッシュごとに分割するものにチェックを入れます。後から「ツール → スタート画面…」で開き直せます。
2. **判定結果を確認**：「レイヤー」表でパーツの種類、左右、差分設定を確認し、誤りはその場で修正します。
3. **プレビューと調整**：「プレビュー」ワークスペースで動きと物理を確認し、必要に応じて編集・リギング・アニメーション・物理演算の各ワークスペースで調整します。
4. **保存と書き出し**：`Ctrl+S` で `.psd2live` を保存し、`Ctrl+G` で書き出し設定を開いて `.cmo3` や `.moc3` 一式を出力します。

<img src="../imgs/import-split.webp" width="560" alt="メッシュごとのレイヤー分割：legwear、footwear、eyelash、front hair がそれぞれ 2 パーツとして検出されている">

**初めての方は「ヘルプ → チュートリアル…」（`F1`）を開いてください。** 対応する操作箇所を強調表示し、現在のキー設定で案内します。初心者コース（18 講座）と Cubism 経験者コース（13 講座）があり、[操作早見表](guide/USER_GUIDE.md)はその文字版です。

## 素材の準備

自動生成の品質はレイヤー構成で大きく変わります。特に重要なのは次の点です。

- 白目・瞳・上まつ毛を分け、まぶたに隠れる瞳の部分も描いておく
- 開いた口の素材を用意する（または上の歯・下の歯・舌を分ける）
- 前髪と後ろ髪を分け、隠れる部分にも余裕を持たせる
- 体はおおむね正面・直立にし、レイヤー効果や文字はラスタライズする

名前の一覧は [PSD の準備と命名](spec/PSD_LAYER_SPEC.md)を参照してください。判定できなかったレイヤーも保持され、画面上で種類を指定できます。

## 出力ファイル

| ファイル | 用途 |
| --- | --- |
| `.psd2live` | PSD2Live のプロジェクト。元の PSD、素材、設定、すべての編集と履歴の分岐を保存します。作業を続けるにはこれを保存してください |
| `.cmo3` | Cubism Editor のモデルプロジェクト。公式エディタでの確認と仕上げに使います |
| `.model3.json` + `.moc3` + テクスチャ・物理・モーション | ランタイム用一式。まとめて納品し、`.model3.json` から読み込みます |
| `.psd2live.json` | 書き出し診断レポート。プロジェクトの代わりにはなりません |

書き出し先は Cubism 3.0 – 5.0（既定 5.0）から選べます。対象バージョンで表現できない機能は変換され、レポートに記録されます。書き出しに成功しても全ランタイムで同じ見た目になるとは限らないため、納品前に対象のエディタと実行環境で確認してください。対応範囲は[ランタイムと書き出しの境界](../zh/spec/RUNTIME_EXPORT_ARCHITECTURE_AND_GAPS.md)（中国語）を参照してください。中立リグ IR を経由して、VTube Studio モデル、PSD2Live ランタイムモデルと Web プレイヤー、ポーズのレイヤー付き PSD、PNG 連番、スプライトシート、GIF、動画にも書き出せ、毎回損失レポートが付きます。[書き出しターゲット](../zh/spec/EXPORT_TARGETS.md)（中国語）を参照してください。

内蔵レンダラーは公式 SDK なしで動作します。[Cubism ネイティブプレビュー](guide/CUBISM_SDK_SETUP.md)は任意で、公式ランタイムの描画と物理との比較に使えます。

## Agent との連携（MCP）

1. PSD2Live を起動したまま **ツール → MCP → MCP 接続とセットアップ…** を開きます。
2. 使用するホストに合った設定をコピーします。Streamable HTTP 対応のホストは直接接続し、Stdio のみのホストはリポジトリ直下の [`mcp_proxy.py`](../../mcp_proxy.py) を使います。
3. Agent にはまず `workspace_inspect` を呼ばせてください。すべての書き込みは画面操作と同じ履歴に入り、アプリ側で元に戻せます。

リクエストと例は [MCP リファレンス](../zh/agent/MCP_AUTHORING.md)（中国語）にあります。MCP サーバーは画像を生成しないため、新しい素材にはホスト側の画像生成機能が必要です。ツールが呼べても複雑なモデリングが安定するとは限りません。[実測記録](../zh/STATUS.md)には成功例と失敗例の両方を残しています。

## ソースからのビルド

JDK 21 が必要です。Gradle は同梱の Wrapper で実行します。

```bash
./gradlew run                      # GUI を起動（Windows：.\gradlew.bat run または run-gui.bat）
./gradlew run --args="--input examples/tml/psd-input/tml.psd --output build/example-output"   # コマンドラインで生成
./gradlew test                     # テストを実行
./gradlew packageDistributionForCurrentOS   # 現在のプラットフォーム向けインストーラーを作成
```

ソースビルドは内蔵レンダラーを使います。公式 Cubism SDK は各自で入手し、ネイティブブリッジを別途ビルドしてください。CLI の全オプション、パッケージ作成、ネイティブビルドは[開発とコマンドライン](guide/DEVELOPMENT.md)を参照してください。

## 貢献

Issue、再現できる PSD、ドキュメントの修正、コードの改善を歓迎します。

- **不具合報告**：バージョン、OS、再現手順、期待する結果と実際の結果、ログパネルの関連記録を添えてください。

- **Agent の事例**：ホスト、モデル、やり直し回数、コストも記録してください。形式は[実測記録](../zh/STATUS.md)に従います。
