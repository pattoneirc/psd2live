# 操作早見表

[ドキュメント一覧](../../README.md) · [中文](../../zh/guide/USER_GUIDE.md) · [English](../../en/guide/USER_GUIDE.md)

まず **ヘルプ → チュートリアル…**（`F1`）を開いてください。操作箇所と現在のキー設定が画面に表示されます。カタログは全 19 テーマで、初心者コースは下記の 18 講座です。Cubism 経験者コースは用語対応から始まり、一部の入門講座を省略します。「基本フロー」以外の講座は、モデルが開かれていなければ最初に PSD の読み込みかプロジェクトを開くよう求めます。

## 基本の流れ

PSD をインポート（`Ctrl+Shift+O`）→ 分類とプレビューを確認 → 編集 → 保存（`Ctrl+S`）→ 書き出し（`Ctrl+G`）。既存の `.psd2live` は `Ctrl+O` で開きます。

## ワークスペース

画面は上部のワークスペースタブで構成され、タブごとにキャンバスとパネルの配置を持ちます。タブバー右端の **+** から、八つのプリセットまたは空白レイアウトで新規作成できます。右側にレイアウトと用途のプレビューが表示されます（スクリーンショットは中国語 UI）。

![新規ワークスペースメニュー](../../imgs/workspace-presets.webp)

| プリセット | 用途 |
| --- | --- |
| 編集 | 一枚の編集キャンバスでデフォーマ、キーフォーム、ボーンを扱う。プロパティパネルがそろう |
| メッシュ | 階層ツリー、編集キャンバス、メッシュパネルでトポロジーを編集 |
| リギング | 編集キャンバスとライブプレビューを並べ、パラメータパネルを常時表示 |
| アニメーション | モーション一覧、プレビューキャンバス、アニメーションエディタ |
| プレビュー | 大きなプレビューとモーション一覧のみ |
| 物理演算 | プレビューキャンバスとパラメータ・物理パネル。モデルを動かしながら調整 |
| テクスチャ | アトラスのページ、編集キャンバス、テクスチャパネル。各レイヤーのピクセルサイズを確認・調整 |
| 履歴 | 履歴ツリーと操作リストのみ。履歴の閲覧と切り替え |
| 空白 | 空のドック。**ウィンドウ** メニューから必要なキャンバスとパネルを追加 |

**レイアウトをリセット** で現在のワークスペースをプリセットの配置に戻します。

### テクスチャワークスペース

各レイヤーには三つのサイズがあります。キャンバス上で覆う矩形（キャンバス単位）、レイヤー自身のラスターのピクセル、テクスチャアトラス内のタイルのピクセルです。「テクスチャ」ワークスペースはこれらを並べて表示し、レイヤーごとに調整します。

- **アトラス**（左）：ページ画像がビュー全体に表示され、編集キャンバスと同じ操作で扱えます。ホイールでズーム、中ボタンまたは Space + ドラッグでパン、`F` で選択範囲にフォーカス、`Home` / `0` でページ全体を表示、`Ctrl+A` でページのタイルをすべて選択します。タイルをクリックするとそのレイヤーを選択し、空白をドラッグすると矩形選択になります（Shift で追加、Alt で除外。編集キャンバスと同じ）。選択はキャンバスやレイヤー一覧と同期します。**タイルをドラッグ** するとピクセルがポインターに合わせてリアルタイムに動き、離すとその位置に置かれます。他のタイルのメッシュ（矩形ではなくメッシュが実際に使うセル）と重なる位置やページ外では移動せず、タイルは赤く表示されます。選択タイルの上辺の外にある **丸いハンドル** をドラッグすると中心を軸に任意の角度で回転します（Shift で 15° 刻み）。回転後もメッシュで重なりを判定します。移動・拡大縮小・回転は描画モードと同じ **編集セッション** で、ページ上の表示だけを変えてモデルを再構築しないため常に滑らかです。変更があるとページ上部中央にセッションバー（ペイントモードと同じバー）が下りてきて変更タイル数を示し、元に戻す／やり直し（Ctrl+Z / Ctrl+Shift+Z）、破棄、**適用**（Enter）ができ、適用するとすべての変更が 1 ステップ（再構築 1 回、履歴 1 件）でコミットされます。ビューが狭いときはボタンがアイコンだけになり、ホバーで名前が出ます。セッション中は配置、自動配置、予算、ロック、画像の置き換えは使えません。**選択タイルの角をドラッグ** すると、対角までの距離に応じて密度を変更し、段階なく連続的に変わり、つかんだ角の対角は動かず、ドラッグ中は新しいサイズで表示します。複数選択では他のレイヤーも同じ比率で変わり、離したときにコミットされます。小さく表示されたタイルには右下の角の外側に一つだけ角が表示されます。拡大して他のタイルのメッシュと重なると赤く表示され、離しても適用されません。移動も吸着せずポインターに追従します。テクスチャパネルの密度スライダーをドラッグしたときも、ページとサイズカードに新しいサイズがリアルタイムに表示されます。タイルをダブルクリックするとフォーカスします。タイルを右クリックすると密度の 2 倍・半分・リセット、サイズのロック、選択タイルの配置、画像の置き換えができ、空白を右クリックすると配置、全選択、ページ全体の表示ができます。左上には編集キャンバスのモードバーと同じフローティングバーがあり、一度だけ配置して結果を保つ **配置** ボタン（隣のドロップダウンには配置オプションだけがあり、配置方法をメッシュ形状（既定。メッシュが実際に覆う領域でタイルを入れ子にし、最もコンパクト）か矩形から選び、範囲を「すべてのタイル」か「選択タイルのみ」から選びます）、**自動配置** ボタン（押すとオンになって点灯し、もう一度押すとオフ。オンでは変更のたびに矩形（MaxRects）で再配置、オフ（新規プロジェクトの既定）では現在の配置を保ち、新しいレイヤーは黙って空き領域に置かれ、元の位置に収まらないタイルだけを通知します。置かれた位置は保たれ、他のタイルを移動・縮小して空いた場所に後続のタイルが詰められることはありません）、複数ページではページ番号が並びます。右上はアトラス予算（ページサイズ 1024–16384、最大ページ数、余白）です。右下は編集キャンバスと同じ表示バーで、ホバーで展開します：テクスチャ、メッシュのワイヤーフレーム、枠線、**密度ヒートマップ**（既定はオフ。キャンバス単位あたりのアトラスピクセル。1 未満は青、約 1 は緑、1 超はオレンジ、凡例は ¼–4）、左下のステータスはポインター下またはドラッグ中のタイル、それ以外はフィットと占有率を表示します。フィットが 100% 未満なら予算に収まらず、ロックされていないタイルがまとめて縮小されます。通知はページ上部に表示され、閉じられます。削除したレイヤー（分割前の元レイヤーを含む）はアトラスを占有せず、表示もされません。
- **テクスチャパネル**（右）：「キャンバス → 元画像 → アトラス」の三つの枠で、選択レイヤーのキャンバス矩形、元画像のピクセル、タイルサイズを示し、実効密度をヒートスケール上に表示します。**テクスチャ密度** のスライダーと ½× / 2× / リセットで倍率（元画像 1 ピクセルあたりのアトラスピクセル、1/64–16、複数選択に一括適用）を変更し、**サイズをロック** はアトラス縮小時もサイズを保ちます。固定済みのタイルは **固定を解除** できます。**画像を置き換え…** は任意の解像度でピクセルを置き換え、キャンバス上の矩形を保ちます（引き伸ばし／全体を収める、メッシュ再構築は任意）。**テクスチャ高解像度化…** はプロジェクトの高解像度化設定を開きます。キャンバス矩形の数値は **キャンバス矩形の数値** に折りたたまれています。何も選択していないときはアトラスの概要、配置方式、予算を表示します。書き出し画面はアトラスの概要だけを表示し、テクスチャワークスペースへ移動できます。アルファ閾値はメッシュパネルの全体設定に移りました。
- **元画像のピクセルのプレビュー**：編集キャンバス右下の表示バーの **元画像のピクセル** をオンにすると、そのキャンバスはアトラスのタイルではなく各レイヤー自身のラスターを描画し、パック後の鮮明さと比較できます。キャンバスごとに保存され、オンの間そのキャンバスはソフトウェア描画になります。プレビューキャンバス（Cubism ランタイム）と書き出しは常にアトラスのピクセルを使います。

作者の編集、バインド、実体化されたメッシュを持つレイヤーでは、キャンバス矩形の移動やメッシュ再構築を伴う画像置き換えは拒否され、理由がアトラスページ上部に表示されます。変更はそれぞれ一つの履歴ノードになり、元に戻せます。対応する Agent 操作は中国語の [MCP_AUTHORING.md](../../zh/agent/MCP_AUTHORING.md#纹理与纹理集) を参照してください。

## 間違えやすい点

- 保存は素材・編集・履歴の保持、書き出しはモデルの受け渡しです。`.psd2live.json` は診断レポートです。
- モデリングのキーフォームはパラメータ上の形状、アニメーションのキーフレームは時刻上のパラメータ値です。
- 変形は形状、編集はメッシュ構造、描画は画素を変えます。描画には独立した適用・破棄の操作があります。
- 一時的な単独表示や静的な非表示と、パラメータで駆動する差分は別です。

襟や髪の前後関係を調整する手順は、[前後分層の図解チュートリアル（中国語）](../../zh/guide/DEPTH_SPLIT.md)を参照してください。

以前のバージョンで行った分割（連結成分・多角形・前後分層）は、分割時の状態をパーツに固定しているため、顔の設定・立ち姿・スケルトン・パーツの分類を後から変えても反映されません。**ツール → 分割記録をアップグレード** でこれらの記録を新形式に書き換えると、パーツは通常のメッシュと同様に生成に参加し、元レイヤーとパーツに加えたキーフォーム・パス・ウェイト・グルーは保持されます。古い記録があるときだけ有効で、全体が一つの履歴として取り消せます。安全に書き換えられない記録はそのまま残り、理由がステータスバーに表示されます。プロジェクトを開いただけでは書き換えません。

髪・衣装のシミュレーション、固定点ウェイトとベイクの手順は、[シミュレーション図解チュートリアル（中国語）](../../zh/guide/SIMULATION_TUTORIAL.md)を参照してください。

## 初期ショートカット

以下は初期設定（Photoshop 風）のキーです。**設定**で Blender 風・Cubism 風のプリセットに切り替えたり、個別に変更したりできます。現在の割り当ては **ヘルプ → ショートカット一覧…** で確認できます。

| 操作 | キー |
| --- | --- |
| プロジェクトを開く / PSD をインポート | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 別名で保存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` または `Ctrl+Y` |
| モデルを書き出し / PSD を書き出し | `Ctrl+G` / `Ctrl+Shift+E` |
| PSD を再解析 | `Ctrl+R` |
| テクスチャ高解像度化 | `Ctrl+U` |
| チュートリアル | `F1` |
| 拡大縮小 / 移動 | ホイール / 中ボタンドラッグまたは Space + 左ドラッグ |
| 選択対象に合わせる / 視点をリセット | `F` / `Home` または `0` |
| 一時選択 / クイックプレビュー切替 | `Z` を押している間、離すと復帰 / バッククォートキー（Esc の下） |
| 確定 / 取消 | `Enter` / `Esc`（使用中のツールの表示に従う） |

## 確認とトラブルシューティング

| 症状 | まず確認すること |
| --- | --- |
| パーツが正しく動かない、動かない | [素材命名](../spec/PSD_LAYER_SPEC.md)と「レイヤー」表の種類・左右、マスク、親 |
| 静止ポーズは正常だが動くと破綻する | アニメーション・物理パネルで再生して確認（静止ポーズ 1 枚では動きは分からない） |
| パネルが見えない | ウィンドウメニューのパネル表示、または右上の「レイアウトをリセット」 |
| キャンバスにモデルが見えない | キャンバスを合わせ（`F` / `Home`）、レイヤーの表示を確認 |
| 書き出しに失敗する、変換の警告が出る | ログパネル、`.psd2live.json` レポート、書き出し対象バージョン |
