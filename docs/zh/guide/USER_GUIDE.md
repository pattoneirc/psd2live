# 操作速查

[文档目录](../../README.md) · [English](../../en/guide/USER_GUIDE.md) · [日本語](../../ja/guide/USER_GUIDE.md)

先打开 **帮助 → 教程…**（`F1`）。交互教程会高亮控件、切换到相关面板，并按你当前的快捷键提示操作；本文是它的文字版，用于回看，不逐个讲解按钮。

## 最短流程

导入 PSD（`Ctrl+Shift+O`）→ 检查图层分类与预览 → 按需编辑 → 保存工程（`Ctrl+S`）→ 导出（`Ctrl+G`）。已有 `.psd2live` 用 `Ctrl+O` 打开。

已有 Cubism 模型可在 **文件 → CMO3 导入** 中选择：**替换导入** 按 ID 替换文件中的对象并加入新对象，保留文件中未出现的内容；**全新导入** 清空当前模型后导入，模型内容仅来自该 CMO3。两种方式均不自动生成预设，导入的参数、关键形、变形器、贴图和物理可随工程保存。

## 工作区

界面由顶部的工作区标签组成，每个标签有自己的画布与面板布局。点标签栏右侧的 **+** 新建工作区，可选八种预设或空白布局，右侧会预览布局与用途：

![新建工作区菜单](../../imgs/workspace-presets.webp)

| 预设 | 用途 |
| --- | --- |
| 编辑 | 一块编辑画布，处理变形器、关键形和骨骼，属性面板齐全 |
| 网格 | 层级树、编辑画布与网格面板，编辑网格拓扑 |
| 绑定 | 编辑画布与实时预览并排，参数面板常驻 |
| 动画 | 动作列表、预览画布与动画编辑器 |
| 预览 | 大尺寸预览，只保留动作列表 |
| 物理 | 预览画布加参数与物理面板，边牵动模型边调整 |
| 纹理 | 纹理集页面、编辑画布与纹理面板，查看并调整每个图层的像素尺寸 |
| 历史 | 只有历史树和它的操作列表，浏览与切换历史 |
| 空白 | 空的停靠区，从 **窗口** 菜单添加需要的画布和面板 |

**重置布局** 恢复当前工作区的预设布局。

### 纹理工作区

每个图层有三种尺寸：在画布上覆盖的矩形（画布单位）、自身栅格的像素，以及它在纹理集中的图块像素。「纹理」工作区把三者并列显示，并逐层调整：

- **纹理集**（左）：整页图像铺满视图，操作方式与编辑画布一致——滚轮缩放，中键或 Space + 拖动平移，`F` 聚焦所选、`Home` / `0` 适应页面，`Ctrl+A` 选择本页全部图块。单击图块选择对应图层，在空白处拖动框选（Shift 追加，Alt 减选，与编辑画布相同）；选择与画布和图层列表同步。**拖动图块** 时图块的像素随指针实时移动，松开后移到该位置，只提交一次，与其他图块（按网格排布的图块按其网格区域）重叠时不移动；**拖动所选图块的角点** 按到对角的距离缩放密度（图块按新尺寸实时显示），沿 ¼ 次幂步长吸附，多选时其余图层按同一比例缩放，松开后提交；图块显示得太小时只在右下角外侧显示一个角点；放大后会压到邻居时边框变为橙色，提交后邻居会被移到空闲位置；纹理面板的密度滑块拖动时，页面和尺寸卡片同样实时显示新尺寸；双击图块聚焦。右键图块可加倍/减半/重置密度、锁定尺寸、排布所选图块、替换图像；右键空白处可排布、全选或适应页面。左上角是与编辑画布模式栏相同的浮动栏：**排布** 按钮一次性排布并保存结果，旁边的下拉菜单只放排布选项：单选的排布方式——按网格形状（默认，图块按网格实际覆盖的区域互相嵌套，最紧凑）或按矩形，以及“仅排布所选图块”开关；**自动排布** 开关——开启时每次修改后按矩形（MaxRects）重新排布，关闭时（新工程默认）保持当前布局，新增图层静默放入空闲区域，只有原位置放不下的图块会提示，放入后的位置会被保留——移动或缩放其他图块空出的位置不会被后面的图块自动填补；多页时还有页码。右上角是纹理集预算（页面尺寸 1024–16384、最多页数与间距）。右下是与编辑画布相同的显示栏，悬停展开：纹理、网格线框、轮廓与 **密度热力图**（默认关闭；按“每画布单位的纹理集像素”着色：蓝色低于 1，绿色约为 1，橙色高于 1，图例 ¼–4），左下状态条显示悬停或拖动中的图块，否则显示适配比例与占用。“适配”低于 100% 表示预算放不下，所有未锁定图块一同缩小，提示显示在页面上方，可关闭。已删除的图层（包括拆分前的原图层）不占用纹理集，也不显示。
- **纹理面板**（右）：以“画布 → 原图 → 纹理集”三格显示选中图层的画布矩形、原始像素与图块尺寸，并在色标上标出实际密度。**纹理密度** 滑块与 ½× / 2× / 重置按钮调整倍率（每个原始像素对应的纹理集像素，1/64–16，多选时统一设置），**锁定尺寸** 让图层在纹理集需要缩小时保持尺寸；已固定的图块可 **取消固定**。**替换图像…** 以任意分辨率替换像素并保持画布矩形，可选“拉伸 / 完整容纳”以及是否用新像素重建网格；**纹理高清化…** 打开工程的高清化设置。画布矩形的精确数值折叠在 **精确画布矩形** 中。未选择图层时显示纹理集概况、布局方式与预算。导出对话框只显示纹理集摘要，并可跳转到纹理工作区；透明阈值移到网格面板的全局设置中。
- **原始像素预览**：编辑画布右下显示栏的 **原始像素** 让该画布直接采样各图层自身的栅格，而不是纹理集图块，用于对比打包后的清晰度。该选项按画布保存，打开时此画布使用软件绘制；预览画布（Cubism 运行时）与导出始终使用纹理集像素。

移动画布矩形、替换图像并重建网格对已有作者编辑、绑定或物化网格的图层会被拒绝，原因显示在纹理集页面上方。每项修改都是一个历史节点，可撤销。Agent 侧的同名操作见 [MCP_AUTHORING.md](../agent/MCP_AUTHORING.md#纹理与纹理集)。

## 按交互教程学习

教程目录共有 19 个主题：零基础路线包含下列 18 课；有 Cubism 经验的路线会先读一章术语对照，再跳过部分入门课。除「基础流程」外，各章在没有打开模型时会先要求导入 PSD 或打开工程。

| 课 | 主题 | 操作要点 |
| --- | --- | --- |
| 1 | 基础流程 | 导入分层 PSD，检查预览、图层预设和模型预设，再选择导出格式；贴图图集在导出窗口中设置。 |
| 2 | 工作区导览 | 编辑页改模型，预览页看效果，历史页切版本；每个画布标签页独立保存镜头和视图开关。 |
| 3 | 层级树与模式条 | 在树中选择、搜索或改父级；透明图片可拖入树中，放置确认后成为图层。绘制顺序决定遮挡，父级决定继承形变。 |
| 4 | 图层类型与差分 | 「预设」使用部件算法；「开关差分」用一个参数控制有无；「切换差分」用同一参数及不同关联 ID 实现多选一。 |
| 5 | 参数与关键形 | 拖滑块或 XY 控件检查姿态；右键参数键标记吸附。先确定目标参数值，再编辑关键形。 |
| 6 | 选择模式 | 选择对象，利用框选、套索和树画布联动定位；只选对象，不修改几何。 |
| 7 | 创建变形器 | 选目标 → 树右键添加父级或子级变形器 → 调整放置预览 → 确认。 |
| 8 | 变形模式 | 调整当前姿态的控制点、整体变换或形变笔刷；注意当前 L1 / L2 编辑层级。 |
| 9 | 编辑模式 | 修改网格拓扑，例如细分、连接、切割与删除；完成后复查参数姿态。 |
| 10 | 绘画模式 | 先选图层，再用画笔、橡皮、填充等修像素；会话内独立撤销，完成后应用或放弃。 |
| 11 | 检视面板 | 根据所选对象修改名称、归属、遮罩、绘制顺序、透明度与颜色等属性。 |
| 12 | 工具细节 | 调整当前工具的半径、硬度、强度、形状等；右键菜单也随模式和工具变化。 |
| 13 | 骨骼绑定与编辑 | 在骨骼模式中新建、挤出、复制、镜像骨骼，批量绑定画元，用 FK/IK 摆姿态，绘制与清理蒙皮权重并保存姿态；在面板配置参数采样容差与关键形上限。导出时烘焙为 Cubism 参数、变形器与关键形。 |
| 14 | 动画与动作编辑器 | 用各预设的调节项调整生成动作；在时间线上编辑参数轨道与关键帧，支持自动插帧、默认贝塞尔缓动、轨道关键帧标记与多画布姿态共享。 |
| 15 | 物理画布调试 | 设置输入、摆锤与输出，用范围和实测最大值校准输出倍率。 |
| 16 | 布料与头发模拟 | 在模型预设「物理与模拟」中生成头发与服装模拟（没有时先生成），了解头发三种模式与服装选项；再在模拟面板查看物理体，在模拟模式绘制并理解固定点、刚度、保形、质量、阻尼权重，设置胶水、材质预设与数值、输入输出和烘焙选项，烘焙为参数、关键形与 Cubism 摆锤；只有烘焙结果会导出。 |
| 17 | 工程与历史 | 保存 `.psd2live`，在紧凑历史树中搜索节点、高亮分支或双击快速检出；支持独立「历史」工作区预设。 |
| 18 | 贴图高清化 | 配置本地后端，选择 2× / 4×；检查边缘、半透明部件和导出结果。 |

## 容易混淆的概念

头发与服装模拟的分步截图见[模拟图文教程](SIMULATION_TUTORIAL.md)，包含固定点权重调整、烘焙和导出效果检查。

- **保存与导出**：保存保留工作区和历史；导出生成目标软件使用的模型文件。`.psd2live.json` 是报告，不是工程。
- **关键形与关键帧**：参数键上的关键形属于建模，键之间会插值出模型形状；关键帧位于动画时间线，记录某个时刻的参数值。
- **变形与编辑**：变形改变形状；编辑改变控制网格的结构。绘画修改像素，采用独立的应用 / 放弃会话。

### 前后分层：让一个图层穿过另一个部件

分步截图见[前后分层图文教程](DEPTH_SPLIT.md)：从选择衣领与脖子，到创建前后层、橡皮擦修边和检查效果。

例如领子只有一层，却需要形成「后领子 → 脖子 → 前领子」的遮挡：在层级树中右键领子，选择 **前后分层…**，将「穿插对象」设为脖子。弹窗按从前到后的顺序预览三层，点击 **创建并擦除** 即可。

原层由后层和前层两个新图层取代，两层都带原层的完整像素和独立贴图：后层接替原层的变形、胶水、遮罩和模拟，前层复制同样的网格与变形数据，并用胶水将每个对应顶点黏合，完全跟随后层；程序自动设置绘制顺序。原层不再出现在图层列表中，“恢复全部”也不会带回它，撤销可回到分层前。创建完成后会选中前层并进入绘画橡皮擦，擦掉其中的后领子部分，再点击 **应用**。该前层的绘画会自动保留原网格与变形，不弹出重新生成网格的选择。绘画笔画可独立撤销，整个分层操作也进入工程历史。当前支持从 PSD 或图片生成的模型。

也可以多选领子和一个或多个穿插对象，直接右键领子，选择 **将「领子」前后分层**。只复制右键点击的一个 ArtMesh，其余选中对象全部位于前后层之间，保持彼此的绘制顺序，直接生成并进入橡皮擦。右键已经选中的对象会保留多选。在画布的选择模式中，右键菜单也提供此操作，菜单名称明确显示当前要拆分的 ArtMesh。

**升级旧拆分记录**：较早版本的拆分（连通块、多边形、前后分层）把原层拆分时的状态整体固定在部件里，之后改脸部设置、站姿、骨架或部件分类都不会更新这些部件。**工具 → 升级拆分记录** 把工程里这类旧记录改为新格式：部件此后像普通网格一样参与生成，你在原层和部件上做的关键形、路径、权重与胶水保留。只有存在旧记录时菜单可用；全部升级合为一步历史，可撤销；个别记录无法安全升级时保持原样，状态栏列出原因。打开工程时不会自动升级。
- **显隐与差分**：树中的临时独显、图层静态显隐用于编辑检查；需要随参数切换时，设置差分或不透明度关键形。

## 常用快捷键

以下为默认（Photoshop 风格）键位。**设置**中可切换为 Blender 或 Cubism 风格预设，也可逐项自定义；**帮助 → 快捷键…** 显示当前绑定。

| 操作 | 默认键位 |
| --- | --- |
| 打开工程 / 导入 PSD | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` |
| 导出模型 / 导出 PSD | `Ctrl+G` / `Ctrl+Shift+E` |
| 重新分析 PSD | `Ctrl+R` |
| 纹理高清化 | `Ctrl+U` |
| 教程 | `F1` |
| 缩放 / 平移画布 | 滚轮 / 中键拖动或空格 + 左键 |
| 适配所选对象 / 重置镜头 | `F` / `Home` 或 `0` |
| 临时选择 / 快速预览切换 | 按住 `Z`，松开恢复 / 反引号键（Esc 下方） |
| 确认 / 取消当前操作 | `Enter` / `Esc`，具体以当前工具提示为准 |

## 检查与排错

| 现象 | 先检查 |
| --- | --- |
| 部件动作不对或没有动作 | [图层命名](../spec/PSD_LAYER_SPEC.md)与「图层」表格中的类型、侧别；遮罩与父级 |
| 静态姿态正常，运动时穿帮 | 在动画或物理面板中播放检查；单个静态姿态不能代表完整运动 |
| 面板不见了 | 「窗口」菜单中的面板开关，或右上角「重置布局」 |
| 画布上看不到模型 | 先适配画布（`F` / `Home`），再检查图层显隐 |
| 导出失败或提示降级 | 日志面板与导出报告 `.psd2live.json`，以及导出目标版本 |

提交问题时请附版本、操作系统、复现步骤及相关素材。
