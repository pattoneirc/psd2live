# 前后分层图文教程

[文档目录](../../README.md) · [操作速查](USER_GUIDE.md) · [画布编辑](CANVAS_EDITOR.md)

一个图层里的不同部分，有时需要分别位于另一个部件的前面和后面。**前后分层**可以快速复制出前后两层，设置遮挡顺序，并用胶水让它们一起变形。你只需在新前层上擦掉应该藏到后面的部分。

本教程用衣领与脖子的穿插演示完整操作，再用头发与肩部装饰说明另一种用法。适用于从 PSD 或图片生成的模型；导入的 CMO3 模型暂不支持此功能。

## 1. 找出需要前后遮挡的部分

下图中，领口后侧盖住了脖子。因为整个领子都在同一个图层里，直接把它移到脖子前面或后面，都会有一部分遮挡不正确。

![处理前：领口后侧盖在脖子前面](../../imgs/depth-split/collar-before.webp)

*处理前：本应位于脖子后面的领口，出现在脖子前面。*

我们希望后领口藏在脖子后面，前领片仍盖住脖子下缘：

![目标效果：脖子位于后领口与前领片之间](../../imgs/depth-split/collar-target.webp)

*目标效果：脖子从领口中露出，前后遮挡自然。*

对应的遮挡关系是：

| 位置 | 部件 | 作用 |
| --- | --- | --- |
| 最前 | 衣领所在图层 · 前 | 擦除后领口，只保留需要显示在脖子前面的内容 |
| 中间 | 脖子 | 遮住后领口，被前领片遮挡 |
| 最后 | 衣领所在图层 · 后 | 保留完整原图层，提供后侧内容 |

截图中的领子属于整件上衣的 `topwear` 图层，因此实际分层的是整件上衣。无需先把领子单独拆出来。

## 2. 同时选中上衣和脖子

在编辑画布切换到 **选择** 模式，选中衣领所在的上衣图层，再按住 **Shift** 加选脖子。也可以在层级树中完成多选。

![同时选中上衣与脖子，画布显示两个选框](../../imgs/depth-split/select-layers.webp)

*两个选框分别对应上衣和脖子。上衣是要分成前后两层的对象，脖子是夹在中间的对象。*

可以加选多个需要夹在中间的 ArtMesh，但一次只分层一个 ArtMesh。其余选中对象会一起放在前后层之间，保持彼此的绘制顺序。

## 3. 右键上衣，执行「前后分层」

保持多选，右键要分层的**上衣**，选择 **将「topwear」前后分层**。菜单中的名称随你的图层名称变化；点击前先确认它显示的是要复制的对象。

![右键菜单中红框标出的「将 topwear 前后分层」](../../imgs/depth-split/context-menu.webp)

*红框中的菜单项会直接创建前后层，并进入前层橡皮擦。*

创建完成后，原图层由「`topwear · 后`」和「`topwear · 前`」两个新图层取代，两层都带原图层的完整像素。程序自动安排它们与脖子的绘制顺序，复制网格和变形数据，并黏合前后层的对应顶点，让前层跟随后层运动。原图层不再出现在图层列表中，需要回到分层前时使用撤销。

**如果只选中了上衣：** 在层级树中右键上衣，选择 **前后分层…**，在弹窗的 **穿插对象** 中选择脖子，检查前层／中间／后层关系，再点击 **创建并擦除**。

## 4. 在前层上擦掉后领口

创建后，程序会自动选中新前层，切换到 **绘画** 模式和 **橡皮擦**。先检查画布顶部显示的是「`topwear · 前`」。

放大领口，沿着脖子边缘擦掉前层中本应位于脖子后面的领口区域。下图箭头标出了要擦除的位置。

![在 topwear 前层使用橡皮擦，红箭头指向应擦除的后领口](../../imgs/depth-split/erase-front.webp)

*擦除的是前层里的后领口。原后层保留这些像素，所以擦开后可以显示位于中间的脖子。*

调整橡皮擦大小，先清理区域内部，再用较小的笔刷修边。保留前领片及需要位于脖子前面的内容；也不必清空整件上衣。

擦多了，可以用绘画会话中的 **撤销** 恢复笔画。图中的其他部件在绘画时会变暗，这是编辑显示效果。

## 5. 确认应用，检查不同姿势

擦除完成后，点击画布顶部或工具面板中的 **确认应用**。前后分层生成的前层会自动保留原网格与变形，应用时不需要重新生成网格。

![应用后的衣领：脖子露出，前领片保留在脖子前面](../../imgs/depth-split/collar-result.webp)

*完成后的遮挡：后领口在脖子后面，前领片在脖子前面。*

接着在参数面板检查转头、抬头低头和身体转动，尤其注意领口交界处。若某个姿势仍有后领口盖住脖子，回到前层绘画，用橡皮擦继续修边，再确认应用。

前后层会共同变形，但需要擦掉哪些像素仍由你决定。最后保存 `.psd2live` 工程，保留分层、贴图修改和历史。

## 6. 同样的方法也能处理头发与肩部装饰

下图中的肩部装饰与头发，也需要一部分在前、一部分在后。先找出需要分层的装饰所在图层，以及应夹在中间的头发图层。

![处理前：头发与肩部装饰的遮挡关系需要调整](../../imgs/depth-split/shoulder-before.webp)

*先判断哪些装饰应露在头发前面，哪些应藏到头发后面。*

多选装饰所在图层和相关头发，右键**装饰所在图层**执行前后分层。随后在新前层上擦掉应该被头发遮住的装饰部分。

![肩部装饰前层的擦除过程](../../imgs/depth-split/shoulder-erase.webp)

*只在新前层上修剪需要藏到后面的部分，后层保留完整内容。*

确认应用后，检查头发与装饰交界处，并调整相关参数观察运动中的遮挡。

![处理后：头发与肩部装饰形成前后交错的遮挡](../../imgs/depth-split/shoulder-result.webp)

*完成效果：同一个装饰图层可以同时提供前侧和后侧内容。*

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 找不到画布里的快速分层菜单 | 切到选择模式，同时选中要分层的网格与至少一个中间对象；也可从层级树的「前后分层…」打开弹窗 |
| 菜单里显示的对象不对 | 右键要复制的对象；衣领例子应是上衣，不能是脖子 |
| 创建后外观看起来还没变化 | 新前层起初仍是完整复制，需要用橡皮擦去掉其中应被遮挡的部分 |
| 提示先应用或放弃绘画 | 先处理当前尚未提交的绘画会话，再创建前后分层 |
| 正面正常，转动时仍穿插 | 检查相关参数的多个姿势，回到前层补擦并修边 |
