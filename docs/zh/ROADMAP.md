## 已有基础

PSD 自动建模、桌面四种编辑模式、绘画会话、工程与分支历史、基础 CLI 导出、交互教程、参数 / 动画 / 物理面板以及本地 MCP 已有实现。不要再把这些整体列为“待实现”；其具体缺口见下文。

## 编辑与格式

- [ ] 补齐 Blend Shape 创建、限制曲线与产品编辑流程。
- [ ] 扩展 Glue 配对、权重编辑和修复诊断。
- [ ] 物理的风力等全局设置与更多输入 / 输出类型。
- [ ] 模拟：示例模型上裙子与头发烘焙结果的官方运行时视觉验收；融合变形模态参数被摆锤驱动在 Cubism Editor 中的读回确认；进一步缩短烘焙耗时（目前 tml 后发约 6–8 秒）；逐个模态拟合在会甩出鞭梢的细长发束上比一起拟合略差（旧求解器上 R² 0.60 对 0.66）；按面积分配质量后参考模拟在转头时略粗（粗糙度 0.095，原 0.075）；模型预设烘焙数据在新材质模型下重测；可绘制的纹理方向；拖动时导出摆幅约为模拟六成（现由夸张系数补偿）；风力等力场导出；刚体链与软体（见[模拟与烘焙](guide/SIMULATION.md)）。
- [ ] 统一 Motion / Expression / Pose / UserData 等边车的工程模型和引用维护。

## 格式与多目标导出

按 `docs/local` 中的格式设计分阶段推进；已实现的模块与目标见[中立绑定 IR 与导出目标](spec/EXPORT_TARGETS.md)。

- [x] 引擎拆为独立 `:umamo` 模块，消除对产品层的反向引用，删除 KRA / CLIP 读取器等无入口代码。
- [x] 中立绑定 IR（MIT）与 `PuppetModel` 双向无损转换器；moc3 / cmo3 改为从 IR 编译，导出结果与重构前逐字节一致。
- [x] 导出框架（能力描述、损失报告、编译器版本）、光栅类目标（PNG 序列、精灵表、GIF）、指定姿势的分层 PSD、`export` 命令与导出对话框入口。
- [x] 文档层样板：依赖图、内容哈希缓存与三方合并框架；摆动生成结果上的编辑以覆盖保存并在重新生成时合并（见[文档层](spec/DOCUMENT_LAYER.md)）。
- [ ] 其余生成器接入依赖图与覆盖；代价高的生成器接入生成缓存；工程格式 v2 与 v1 一次性迁移。
- [ ] Spine 4.2、DragonBones、glTF、视频（ffmpeg）等目标。
- [ ] 求值器与渲染器统一到运行时核心，Godot 运行时与 `.p2lrt`。
- [ ] 软件绘制的光栅导出补齐混合模式、乘算 / 屏幕色与按纹理 alpha 的遮罩；保真度对比工具。
