# 更新日志

[文档目录](../README.md) · [下载](https://github.com/tsunehimatoi/psd2live/releases)

只记录使用者能感知到的变化。v1.4.2 及更早的版本见 [Releases](https://github.com/tsunehimatoi/psd2live/releases)。

## 未发布

距 v2.0.4 改动较大：新增多种导出格式和独立运行时，纹理可以逐层调整，MCP 接口重新设计。旧工程照常打开。

### 新增

- **更多导出格式**：**文件 → 导出为** 新增 VTube Studio、PSD2Live 运行时模型、网页播放器、PNG 序列帧、精灵表、GIF、APNG、WebP 动图、MP4、WebM、ProRes 4444 和指定姿势的 PSD。每次导出附带损失报告，说明目标格式丢失了什么。视频与动图需要自行安装 ffmpeg。
- **PSD2Live 运行时**：开源（MIT）的 Rust 运行时，可在浏览器、Godot 4 或任何能调用 C 接口的程序中播放导出的模型，自带眨眼、呼吸、视线跟随和口型。
- **纹理工作区**：逐层调整纹理密度；在纹理集页面上直接拖动、缩放图块；按网格形状紧凑排布，布局保持不变，直到你要求重新排布。
- **保留原始分辨率**：导入的图片、素材和 CMO3 贴图不再缩到画布分辨率，绘画在图层自身的分辨率上进行。
- **MCP 重新设计**：公开操作从 25 个增至 181 个，可分页发现；最多 128 项编辑可原子提交，也可先试运行检查几何问题；耗时操作作为后台任务执行。旧的工具名已删除，需按新接口接入。
- 实验性：Spine 4.2、DragonBones 5.5、glTF 2.0 导出，仅限命令行。

### 改进

- **拆分更可靠**：按网格拆分、多边形拆分和前后分层得到的部件直接取代原图层，并参与自动生成。之后修改脸部设置、站姿或骨架，部件会跟着更新；原图层不再占用纹理集。
- **关节更自然**：骨骼弯曲时，肘、膝等关节按实测的人体关节姿态塑形，内侧不再出现纹理折叠。
- **手工修改不丢失**：在摇摆、模拟烘焙等生成结果上的修形，重新生成后按三方合并保留；冲突或已失效的修改会在检查器中提示。
- **文件菜单重新整理**：分为「导入」「导出 Live2D 模型」「导出为」三组。
- **画布与参数**：网格选择与框变换分开；变形工具作用于选中的参数关键点；添加或拖动关键点默认连续移动，选择步长后才吸附。
- **工程格式 v2**：未改动的内容在历史修订之间共享。旧工程照常打开，保存时自动转换。
- **更快**：修改分类或单个图层的网格时只重算受影响的部分；打开工程时复用已保存的骨架结果；编辑提交不再每次重建整个模型；Cubism 原生预览改为就地更新。
- **结果可复现**：同一个 PSD 每次生成的骨架和导出文件完全一致。

### 修复

- 绘画后重建网格时，位于骨骼、站姿变形器、修改过的格子或导入变形器下的网格不再偏移或缩小。
- 动画播放、参数滑块与画布姿势保持同步；平滑跟踪的速度不再受帧率影响。
- 纹理集中新放入的图块不再跳进其他图块空出的位置。
- Windows 上连续快速保存时偶尔替换文件失败。

## v2.0.4 · 2026-10-04

- 修复 2.0.3 安装包缺少运行时、GPU 绘制实际未生效的问题。

## v2.0.3 · 2026-10-03

- 画布改用 GPU 渲染，整体更流畅。
- 大尺寸 PSD 按比例缩放网格采样，避免顶点过多。

## v2.0.2 · 2026-10-02

- 模拟烘焙更可调：可为每个输入设置训练范围；上下参数可选自动 / 开 / 关；每个输出可单独修改参数 ID、范围和增益，无需重新烘焙；物理面板对模拟摆锤的修改在重新烘焙后保留。详见[模拟与烘焙](guide/SIMULATION.md)。
- 修复物理模拟 Y 方向表现异常。

## v2.0.1 · 2026-10-02

- 新增前后分层：把图层拆成前层和后层，用 Glue 保持同步变形，适合衣领、头发等穿插遮挡。详见[前后分层图文教程](guide/DEPTH_SPLIT.md)。
- 参数快照支持悬停预览：鼠标悬停即可在画布上半透明预览保存的姿态。

## v2.0.0 · 2026-10-02

- **统一开始界面**：导入 PSD 后在一个界面选择快捷方案、模型预设和网格拆分，也可从「工具 → 开始界面」重新打开。
- **更自然、可调的 Rig 与动作**：重建待机与身体层级，动作按模型骨骼与比例自适应；新增大小变（头身比）、前后倾（立体弯腰）等可调变形。
- **动作预设**：分为「基础动作 / 骨骼动作」，骨骼动作可逐项启用和调节。
- **布料与头发模拟**：新增材质预设，上下方向可单独烘焙为 Y 参数，预览可切换「导出效果 / 参考模拟」。
- **CMO3 导入**：支持新建工程或替换当前模型。
- 教程扩展到模拟、模型预设、骨骼与动作调节。

## v1.6.0 · 2026-10-01

- 新增编辑器内 2D 布料与头发模拟：顶点权重组、权重笔刷、参考模拟、材质调节，结果可烘焙为 Cubism 参数、关键形与摆锤。
- 骨骼工作流全面升级：创建、挤出、镜像、细分、融合、多选变换，FK / IK、关节约束、姿态快照、批量绑定与权重绘制。
- 模型预设可按服装宽松程度自动配置上衣、裙子、裤子等的模拟。
- 画布新增统一的模式菜单，加入「模拟」和「骨骼」模式。

## v1.5.0 – v1.5.1 · 2026-09-29

- 动画编辑器支持自动插帧，参数变化自动记录关键帧。
- 骨骼参数的采样容差、角度间隔和关键形上限可配置；蒙皮权重沿连通网格扩散，过渡更自然。
- MCP 新增骨骼与动作创作工具。
- 预览参数拖动更流畅；网格外的杂色像素不再影响生成。
