# 更新日志

[文档目录](../README.md) · [下载](https://github.com/tsunehimatoi/psd2live/releases)

只记录使用者能感知到的变化。v1.4.2 及更早的版本见 [Releases](https://github.com/tsunehimatoi/psd2live/releases)。

## 未发布

### 改进

- **运行时模型格式 2.0**：导出的 `.p2lrt` 改为分块格式，可压缩、可校验，并带参数分组与吸附值，便于今后加入新功能而不破坏旧文件。运行时、网页播放器和 Godot 节点同时读新旧两种格式；需要给旧版播放器使用时，在导出设置中勾选「版本 1」。

### 新增

- **工具选项栏**：画布模式条下方显示当前工具的数值与操作（半径、强度、硬度、不透明度、模式、确认 / 取消等），左右拖动数值即可调节，单击弹出滑块。右键菜单显示同一组数值和该工具的操作，两处范围一致，`[` `]` 等笔刷快捷键也调整同一个值；工具面板只保留精确变换、创建默认值、路径列表、骨骼绑定与权重、调色板等高级设置。
- **数字键选项**：`1`–`5` 选择当前模式或工具的第 n 项——变形模式的级别、编辑模式的点 / 边 / 面，以及笔刷形状、胶水与骨骼子工具、权重组种类、绘画形状；工具栏在各项旁显示对应数字。
- **工具栏「创建」组**：选择、变形、编辑模式的左侧工具栏新增「创建」，可直接放置 Warp、Rotation 与变形路径，与层级树的添加菜单相同。
- **运行时高级模式**：导出的运行时模型可在播放时开启，默认关闭，关闭时与 Cubism 效果完全一致。
  - **骨骼蒙皮**：手臂、尾巴等骨骼弯折在关键帧之间沿真实弧线运动，不再走直线；宿主可以读取骨骼位置来挂接物件。
  - **实时模拟**：已烘焙的布料和头发按编辑器的模拟实时运行，可加风。
  - **碰撞**：可在模拟中添加沿身体网格的圆或胶囊碰撞体（`obstacles`），烘焙同样会学到碰撞后的运动。
- **部件互斥与 zstd 压缩**：导出设置可指定部件互斥组（如两种手臂只显示其一），运行时切换时自动淡入淡出；块压缩可选 zstd。
- **表情与点击区域**：运行时模型带有微笑、悲伤、生气、惊讶四种表情，以及头部和身体的点击区域。网页播放器和 Godot 节点可以切换表情、做点击检测和开关高级模式。

### 修复

- **画布工具与菜单**：工具栏展开较长时下方的工具不再穿透到画布；变换工具、权重渐变、骨骼模式和吸管的右键菜单不再为空；胶水工具在没有选中两张网格时改为禁用并说明原因，不再消失；形状工具的线宽与画笔大小分开；骨骼权重笔刷可用 `[` `]` 调整大小；Warp 网格尺寸标签随界面语言显示。
- **运行时参数逐帧累积**：网页播放器和 C 接口在每帧更新时把呼吸、视线、眨眼和加法表情叠加在上一帧的结果上，播放一段时间后角度等参数会漂到数万。现在每帧都从宿主设置的姿势重新计算。

## v3.0.1 · 2026-10-08

### 新增

- **韩语界面**：可在设置中选择，命令行用 `--lang ko`。
- **语言切换**：语言菜单改为标题栏右侧、主题切换旁的地球图标；切换后整个窗口立即换成新语言。
- **网格贴合纹理**：新工程默认「按贴图像素描出轮廓」，按每个图层自身的像素生成网格，比画布像素还细的笔画也会留在网格内。旧工程保持原有方式和网格不变。
- **网格包裹**：新增网格设置「包裹」（可全局设置，也可按图层覆盖，命令行 `--mesh-wrap`），把睫毛、发梢、手指等细小突起包进同一个轮廓，顶点明显减少。默认关闭，旧工程不受影响。
- **Windows 附带 ffmpeg 的安装包**：带 `-ffmpeg` 后缀的 zip / exe / msi 内置 ffmpeg，视频与动图导出无需另行安装。
- **卸载时可删除用户数据**：在 Windows 的「卸载或更改程序」中选择删除后，可勾选「同时删除我的 PSD2Live 数据」（默认不勾选）。

### 改进

- **图标统一**：工具栏以外的图标按同一套网格重绘，高分屏上线条不再变细，颜色只用于表达含义。
- **骨架编辑更快**：创建、绑定或移动骨骼时只重新烘焙受影响的肢体，并行计算；大尺寸工程上移动手臂关节从约 2–3 秒降到 1 秒以内。
- **保存与打开更快**：保存时不再重新编码所有图像，也不再解包整个归档做校验；打开大工程时图像并行解码。
- **大尺寸工程更流畅**：纹理集的填充、分类和合成，以及指定姿势的 PSD 导出明显加快。
- **安装与升级**：升级或重装默认装回原来的目录，不再询问目录非空；重新构建的同版本安装包会替换已安装的版本，而不是并存。

### 修复

- **Windows 卸载或升级会清空安装目录**，保存在安装目录下的工程会丢失。现在只删除安装的文件；新建工程的默认位置改为「文档\PSD2Live」。**从 3.0.0 升级前，请先把安装目录中的工程移到别处。**
- 另存为不再默认指向当前打开的文件；覆盖确认改在窗口内弹出；编辑尚未完成时请求的另存为不会被随后的 Ctrl+S 变成普通保存；文件选择框不会再跑到主窗口后面。
- 切换编辑 / 预览模式时视角和画布大小保持不变。
- 启用骨架后，原本拆分在手臂悬挂变形器下的部件重放时报「Art primitive parent is missing」。
- 绑定到骨骼、又被手动放到其他变形器下的网格，烘焙后位置错乱或超出范围。
- 修改已绑定网格的拓扑或撤销后，重新打开工程时骨架结果与编辑时不一致。
- 生成后新加入的图层在重绘后网格被悄悄重新生成，之后重建报「Mesh migration baseline changed」。
- Cubism 预览帧偶尔被软件预览覆盖，姿势丢失。

## v3.0.0 · 2026-10-08

距 v2.0.4 改动较大：新增多种导出格式和独立运行时，纹理可以逐层调整，MCP 接口重新设计。旧工程照常打开。

### 新增

- **更多导出格式**：**文件 → 导出为** 新增 VTube Studio、PSD2Live 运行时模型、网页播放器、PNG 序列帧、精灵表、GIF、APNG、WebP 动图、MP4、WebM、ProRes 4444 和指定姿势的 PSD。每次导出附带损失报告，说明目标格式丢失了什么。视频与动图需要自行安装 ffmpeg。
- **PSD2Live 运行时**：开源（MIT）的 Rust 运行时，可在浏览器、Godot 4 或任何能调用 C 接口的程序中播放导出的模型，自带眨眼、呼吸、视线跟随和口型。
- **纹理工作区**：逐层调整纹理密度；在纹理集页面上直接拖动、缩放图块；按网格形状紧凑排布，布局保持不变，直到你要求重新排布。
- **保留原始分辨率**：导入的图片、素材和 CMO3 贴图不再缩到画布分辨率，绘画在图层自身的分辨率上进行。
- **MCP 重新设计**：公开操作从 25 个增至 181 个，可分页发现；最多 128 项编辑可原子提交，也可先试运行检查几何问题；耗时操作作为后台任务执行。旧的工具名已删除，需按新接口接入。
- 实验性：Spine 4.2、DragonBones 5.5、glTF 2.0 导出，仅限命令行。

### 改进

- **拆分更可靠**：按网格拆分、多边形拆分和前后分层得到的部件直接取代原图层，并参与自动生成。之后修改脸部设置、站姿或骨架，部件会跟着更新；原图层不再占用纹理集。
- **关节更自然**：骨骼弯曲时，肘、膝等关节按实测的人体关节姿态塑形，内侧不再出现纹理折叠。
- **手工修改不丢失**：在摇摆、模拟烘焙等生成结果上的修形，重新生成后按三方合并保留；冲突或已失效的修改会在检查器中提示。
- **文件菜单重新整理**：分为「导入」「导出 Live2D 模型」「导出为」三组。
- **统一的变换框**：「变换」工具、Warp / 图层放置框和纹理集图块使用同一套变换框；拖动角点外侧即可旋转（悬停时角点外亮起带箭头的弧线），新增可拖动的锚点作为旋转和 Alt 缩放的中心（默认在中心，带描边便于辨认），缩放光标随框的角度转动；手柄改为圆角方块与胶囊形，拖动时指针旁显示角度、缩放比例或位移。
- **画布与参数**：网格选择与框变换分开；变形工具作用于选中的参数关键点；添加或拖动关键点默认连续移动，选择步长后才吸附。
- **工程格式 v2**：未改动的内容在历史修订之间共享。旧工程照常打开，保存时自动转换。
- **更快**：修改分类或单个图层的网格时只重算受影响的部分；打开工程时复用已保存的骨架结果；编辑提交不再每次重建整个模型；Cubism 原生预览改为就地更新。
- **结果可复现**：同一个 PSD 每次生成的骨架和导出文件完全一致。

### 修复

- 绘画后重建网格时，位于骨骼、站姿变形器、修改过的格子或导入变形器下的网格不再偏移或缩小。
- 动画播放、参数滑块与画布姿势保持同步；平滑跟踪的速度不再受帧率影响。
- 纹理集中新放入的图块不再跳进其他图块空出的位置。
- Windows 上连续快速保存时偶尔替换文件失败。

## v2.0.4 · 2026-10-04

- 修复 2.0.3 安装包缺少运行时、GPU 绘制实际未生效的问题。

## v2.0.3 · 2026-10-03

- 画布改用 GPU 渲染，整体更流畅。
- 大尺寸 PSD 按比例缩放网格采样，避免顶点过多。

## v2.0.2 · 2026-10-02

- 模拟烘焙更可调：可为每个输入设置训练范围；上下参数可选自动 / 开 / 关；每个输出可单独修改参数 ID、范围和增益，无需重新烘焙；物理面板对模拟摆锤的修改在重新烘焙后保留。详见[模拟与烘焙](guide/SIMULATION.md)。
- 修复物理模拟 Y 方向表现异常。

## v2.0.1 · 2026-10-02

- 新增前后分层：把图层拆成前层和后层，用 Glue 保持同步变形，适合衣领、头发等穿插遮挡。详见[前后分层图文教程](guide/DEPTH_SPLIT.md)。
- 参数快照支持悬停预览：鼠标悬停即可在画布上半透明预览保存的姿态。

## v2.0.0 · 2026-10-02

- **统一开始界面**：导入 PSD 后在一个界面选择快捷方案、模型预设和网格拆分，也可从「工具 → 开始界面」重新打开。
- **更自然、可调的 Rig 与动作**：重建待机与身体层级，动作按模型骨骼与比例自适应；新增大小变（头身比）、前后倾（立体弯腰）等可调变形。
- **动作预设**：分为「基础动作 / 骨骼动作」，骨骼动作可逐项启用和调节。
- **布料与头发模拟**：新增材质预设，上下方向可单独烘焙为 Y 参数，预览可切换「导出效果 / 参考模拟」。
- **CMO3 导入**：支持新建工程或替换当前模型。
- 教程扩展到模拟、模型预设、骨骼与动作调节。

## v1.6.0 · 2026-10-01

- 新增编辑器内 2D 布料与头发模拟：顶点权重组、权重笔刷、参考模拟、材质调节，结果可烘焙为 Cubism 参数、关键形与摆锤。
- 骨骼工作流全面升级：创建、挤出、镜像、细分、融合、多选变换，FK / IK、关节约束、姿态快照、批量绑定与权重绘制。
- 模型预设可按服装宽松程度自动配置上衣、裙子、裤子等的模拟。
- 画布新增统一的模式菜单，加入「模拟」和「骨骼」模式。

- 动画编辑器支持自动插帧，参数变化自动记录关键帧。
- 骨骼参数的采样容差、角度间隔和关键形上限可配置；蒙皮权重沿连通网格扩散，过渡更自然。
- MCP 新增骨骼与动作创作工具。
- 预览参数拖动更流畅；网格外的杂色像素不再影响生成。
