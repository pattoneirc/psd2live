# 骨骼模式工具盘点

[骨骼操作指南](../../guide/SKELETON.md)

> 归档资料：16 项工具均已实现，现行能力表见[骨骼与姿态](../../guide/SKELETON.md#工具一览)。文中的测试计数与骨骼格式版本为当时状态（当前骨骼 JSON 为版本 10）。

## 当前能力

骨骼模式包含「姿态」和「骨骼编辑」两个主工具。骨骼编辑包含 5 个子工具：编辑、新骨骼、挤出、绑定、权重；姿态包含自动／FK／IK。子工具沿用变形笔刷形状的左侧展开行 UI，切换保留同一草稿，完成或离开编辑时作为一次历史记录保存，取消放弃草稿。

| 区域 | 已有操作 | 当前边界 |
| --- | --- | --- |
| 编辑 | 单选、Shift 增减选、框选、骨链选择、平移／旋转／缩放、拖动关节 | 外部连接端点同步；可选择变换包含后代 |
| 新骨骼 | 拖拽创建独立自定义骨骼，显示预览并自动选中 | 不设置父级，不自动继承网格绑定 |
| 挤出 | 从选中骨骼末端延伸子骨骼，支持连续挤出 | 每次创建一根自定义骨骼 |
| 树操作 | 默认长度添加、删除并将子骨骼挂到原父级、尾巴和翅膀开关、重命名、设置／清除父级、连接／断开关节 | 父级设置过滤自身和后代；连接会平移子树，断开保留位置；身体骨骼受删除保护 |
| 绑定 | 单网格绑定、批量点击／框选／列表勾选、高亮预览、批量绑定和解除 | 每个网格只指定一个绑定骨骼；肢体内部自动计算权重 |
| 关节设置 | 关节带宽、最小和最大角度 | 带宽控制自动权重过渡；手工权重在权重子工具编辑 |
| 姿态 | 自动／FK／IK 子工具，重置姿态，保存／应用命名姿态，动画编辑器插入快照 | 自动保留原有身体／末端和 Shift 手势；应用和插入跳过不存在的参数并限制到当前范围 |
| 权重 | 按骨骼颜色显示蒙皮权重，权重子工具增减／替换／平滑，归一化／清理，复制／镜像 | 与角度蒙皮一致：每顶点一根骨骼或两根相邻骨骼；未匹配顶点自动权重 |
| 骨架管理 | 自动推断、启用和禁用、草稿完成和取消 | 一个工程一套骨架 |
| 采样与动作 | 采样容差、角度间隔、关键形上限、骨骼预设动作 | 属于骨骼面板和动画面板能力 |

## 分阶段实施记录

阶段 6：手工权重。权重子工具从已绑定肢体网格开始，蓝到橙显示所选骨骼影响；支持增减、替换和平滑，笔刷连续采样并保留草稿取消。清理检测空值、未知／异肢体骨骼、非相邻影响、数量超限和非归一化行，低权重阈值可调；修复使用自动权重。复制／镜像支持插值、最近顶点和严格同拓扑映射，明确骨骼对应、匹配和未匹配数量后应用。手工数据以静止画布坐标和三角形持久化，新增／加密顶点插值读取；预览、蒙皮挂载规划、焊接和关键形烘焙共用同一结果。结构编辑同步迁移骨骼引用，细分时影响到该骨骼的手工网格恢复自动权重。已验证笔刷四种模式、修复、三种复制方式、镜像、结构迁移、序列化，以及真实烘焙中所有原始／新增顶点的运动。

### 验证与使用边界

- 最终全量验证：`gradlew.bat test` 成功，426 项测试中 423 项通过、3 项跳过，零失败；`git diff --check` 通过。覆盖结构编辑、姿态求解、持久化、工具接口写回及真实网格烘焙。未进行桌面界面的人工交互验收。
- 所有子工具使用骨骼草稿；离开编辑或完成时保存为一条历史，取消丢弃。命名姿态和 IK 目标在姿态模式中即时保存；目标拖拽合并为一次手势历史。
- 手工权重遵守当前角度蒙皮的 1 根或相邻 2 根影响限制，不使用任意多骨线性蒙皮。
- 内置身体／头部副本转为自定义骨骼；细分和融合用于肢体骨骼。融合要求连接、无分叉，避免隐式丢弃分支。
- 手工权重进入真实模型关键形与导出；IK 目标仅是创作约束，导出保存求解后的参数角度和角度范围。
- 三种复制方式都可明确映射骨骼；未匹配或无有效骨骼对应的目标顶点使用自动权重。拓扑方式要求顶点数与三角形索引一致。

阶段 5：IK 目标和求解器。选中末端后设置 1–32 根骨链、1–256 次迭代、像素容差及自动／顺时针／逆时针弯曲。固定目标随工程保存，在修改父级参数时持续求解；拖动十字或输入坐标可移动目标，显示残差，支持禁用和释放。复制／镜像、细分、融合和删除处理目标引用。目标／求解器仅用于创作，模型导出关节参数范围，动画导出求解后的角度，不产生运行时 IK 侧车；动画插入命名姿态可保存求解结果。已添加链长、直链弯曲方向、目标跟随、不可达限制、序列化和结构迁移回归。

阶段 4：批量绑定和命名姿态。绑定子工具先选择目标骨骼，再点击／框选／列表勾选网格，应用前显示高亮、数量和目标，批量操作仍在同一骨骼草稿中。网格点击按三角形命中拆分部件。命名快照保存当前模型参数，应用跳过移除参数并限制到当前参数范围；动画编辑器一次插入到播放头，保留已有关键帧插值和控制柄、创建缺失曲线。已添加批量引用转移、快照序列化与覆盖删除，以及动画插入回归测试。

阶段 3：复制、镜像、细分和融合。复制后的语义肢体骨骼使用独立参数；内置身体和头部副本转为自定义骨骼，避免重复内置变形器。镜像按侧别、语义、变体和名称匹配对侧图层，歧义匹配保持未绑定；明确匹配的绑定转移到镜像骨骼。配对和镜像轴持久化，对称编辑支持关节和选区变换。细分保留首段引用，融合将子骨段几何、绑定和后代合并到父级；两者解除受到影响的镜像配对。已添加引用／序列化回归及实际骨骼烘焙的静止网格、参数唯一性验证。

阶段 2：多选、变换与显式 FK／IK。编辑模式支持 Shift 增减选和空白拖拽框选；拖动身体平移选区，工具详情可按选区中心旋转／缩放，可包含后代。外部相连父尾、子头和兄弟头随共享关节同步，断开的端点不参与。自动姿态保留原快捷手势，FK 和 IK 显式覆盖手势。已添加选区跨框、共享端点、骨链不重复变换、旋转缩放和实际 FK／IK 求解回归测试。

阶段 1：重命名、父级和连接状态。骨骼设置中编辑名称并按 Enter 或移出输入框保存；父级下拉默认保持位置，再开启「连接父骨骼末端」将子树平移到父骨末端。断开后即便坐标重合，也不再联动。已添加名称引用稳定、子树平移、防循环、断开及序列化回归测试。

工具接口同步支持骨骼格式版本 1–9 和新增字段；读取后的骨架可完整写回，包含连接状态、独立参数、镜像配对、命名姿态、IK 目标和手工权重。
