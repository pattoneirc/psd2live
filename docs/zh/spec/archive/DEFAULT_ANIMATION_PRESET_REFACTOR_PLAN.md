# 默认动画重构计划

[文档目录](../../../README.md) · [骨骼操作指南](../../guide/SKELETON.md)

> 归档资料：阶段 1–4 已实现，现行结构见[变形器与参数规范](../DEFORMER_AND_PARAMETER_SPEC.md)和[骨骼与姿态](../../guide/SKELETON.md)；剩余阶段已移入[路线图](../../ROADMAP.md)。文中引用的测试类与部分变形器名已随后续重构删除。

目标：生成的模型动起来接近成品 Live2D。鼠标跟踪时身体自然地朝向鼠标、重心随之转移；待机像活人一样呼吸、四肢放松微动；预设动作按每个模型的原画和骨架生成，不超出人体范围，不像木偶。

## 约束

- 复用现有关键形和骨骼蒙皮关键形，骨骼系统不改。只新增 warp 层级和少量关键形。
- 不批量生成网格关键形。新增 warp 每轴不超过 3 个键；新增网格融合变形只出现在跨关节的腿部网格上，每张不超过 8 个。
- 动画关键帧只放在节拍上，用贝塞尔曲线过渡；导出后仍能在 Cubism Editor 里手工编辑。

## 阶段与进度

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| 1 | 解剖模型、动作合成器、贝塞尔输出；以 Wave、Crouch 为样板 | 已实现 |
| 2 | 用合成器改写 Cheer、Shy、HeadTilt、LegKick、Sway、WeightShift、IdleCute | 已实现 |
| 3 | 待机：按躯干定位的呼吸与身体 Z、四肢放松微动、非整数比的重心周期 | 已实现 |
| 4 | 跟踪：重建身体变形器层级（身体、前后倾、腿部），身体 X 驱动躯干转向和身体横移，身体 Y 驱动整体升降、内八和站直，前后倾为独立参数；预览中身体滞后于头 | 已实现（SDK 预览的原生跟踪与呼吸未改） |
| 5 | `animationVersion`、旧工程升级入口、预设配置与人工修改保护 | 设计中 |

每个阶段结束时在 `tml`、`ds` 样例上对比新旧效果，确认后再进入下一阶段。

## 已实现部分

### 解剖模型（`SkeletonAnatomy`）

从原画静止骨架读出动作需要的“人体”，只用于生成动作，不改变姿势工具的宽角度限制：

- 每只手臂的静止仰角（以竖直下垂为 0°，向身体外侧为正）和骨长；头高、头顶、眼睛高度、脸和身体的中线、腰的高度、地面高度（有腿时）。
- Q 版程度：按头身比从 6 头身（0）到 3 头身（1）。没有腿时只能用肩高估计，偏差较大。
- 舒适范围：大臂 -30°~115°；小臂 -110°~185°，可略过竖直但不会翻过头顶；肘向外屈曲不超过 150°，向内屈曲的余量随大臂抬高而收窄，抬起的手臂不会反折；腕不超过 35°。

### 动作合成器（`MotionSynth`）

- **姿势按目标求解**：在舒适范围和骨骼限制内网格搜索大臂、小臂仰角，取代价最小的解。挥手是“手在脸侧、约眼睛高度、不挡脸”，欢呼是“手在头顶高度、脸外侧”，害羞是“双手在身前、腰上方合拢”。手臂短的模型取够得着的最近姿势，不会强行拉伸。
- **时间按动画原则**：预备动作、缓入缓出、沿骨链逐级滞后（大臂、小臂、手依次晚约 0.06~0.08 秒）、过冲回稳、身体其余部分配合。过冲量会自动缩小到不超出舒适范围。
- **抬手与放下**：抬手时按小臂在画面中的朝向放键，肘先于大臂弯起，手沿弧线贴近身体抬起；放下时小臂先停留片刻，随后肘随手臂下落逐渐伸直，不会出现直臂平举像在指东西的帧。
- **跳跃**：起跳和落地处的关键帧带速度，空中是抛物线，落地由下蹲参数屈膝缓冲。
- **输出**：每条轨迹是时间上的三次曲线，只写已有参数（骨骼角度、姿势参数、标准的角度/身体/呼吸参数），不新增关键形。姿势换算到骨骼参数时，每根骨骼只在自身曲线的关键点和真正转动它的姿势的关键点上取点，单条曲线不超过 24 个键。

### 待机（第三阶段）

- **呼吸与身体 Z 的变形**：仍是原来的 `DeformBodyZBreath`（3×3 关键形，ID 和网格尺寸不变，用户对它的关键形编辑照常重放），只是变形按躯干定位：肩线、腰线取上半身骨骼，没有骨架时取图层推出的肩线和髋线，中线和宽度取上衣。
  - 呼吸从腰线向上逐渐抬起，到肩线达到躯干长度的 3%，肩以上（头、手臂的支点）整体随之上移；胸口绕中线扩张 2.5%，超出躯干两侧的部分只整体平移。腰以下完全不动，原来写死在角色包围盒 42% 高度的胸口，在全身立绘上会落到腹部。
  - 身体 Z 让腰线以上绕腰倾斜（±10 对应约 3°），腰部有平滑过渡，腰以下不动；每行只平移，满足左右对称的行宽校验。原来按整个角色高度的正弦平移，全身立绘上动的是髋部，头和脚都不动。
  - 没有另建局部呼吸 warp：子对象必须落在 warp 范围内，否则会被外推变形；头部旋转和手臂都挂在这一层，局部 warp 包不住它们，换 ID 还会让旧工程里对它的编辑失效。
- **动作**：循环 12 秒（`MotionSynth.idle`）。
  - 呼吸：三次，长度 4.2 / 3.8 / 4.0 秒、深度 0.9 / 0.72 / 0.95，吸气约占四成。身体 Y 晚 0.15 秒点头，头 Y 晚 0.4 秒，另有一个缓慢的抬头低头。
  - 重心：周期 6 秒和 4 秒的两个正弦叠加并归一，半个或三分之一个循环后不重复。重心姿势、身体 X、身体 Z、头 Z、头 X 依次晚 0、0.45、0.7、1.2、1.5 秒；头 X 另有一圈缓慢游移。
  - 手臂：重心姿势本身带动大臂时，小臂、手分别再晚 0.25、0.45 秒，幅度为大臂的 0.6、0.5；没有腿时大臂自己摆 2°（Q 版加大，原画抬起的手臂减半），小臂、手依次滞后。左右手臂幅度和时间略有不同。
  - 尾巴 2.4 秒一摆，翅膀随呼吸。
  - 每条曲线只在转折处放键，相距超过 1.6 秒的两个转折之间再放一个最陡点，循环接缝处值和斜率一致。样例上每条 9~13 个键。
  - 导出的待机眨眼改为 2.7 秒、6.9 秒（连眨两次）和 10.6 秒。
- **IdleCute**：膝盖内扣和双手合拢照旧保持，手臂在合拢姿势上照样放松摆动。

### 跟踪与身体层级（第四阶段）

原来的 `DeformBodyXY` 是包住整个角色的根 warp，身体 X/Y 按 `sin(πv)` 平移各行，脚所在的行也在动；骨架的 `DeformSkelLegs` 又挂在它下面，腿部姿势只对绑定了网格的腿骨生效，`tml`、`ds` 这类腿画在一张图层上的模型用不了。

做法参照 Live2D 的常规制作：
- 身体 X/Y 的 warp 只包上半身的部件，呼吸 warp 是它的子级。
- 身体 X 绕身体中线转：胸前中间的点向参数方向移动，转向前方的一侧放大、另一侧缩小，下身不动。腰以上整体转同样的角度，只在腰到胯之间过渡到 0；从腰到胸逐渐加大的转角会显得在扭腰。
- 身体 Y 时脚保持贴地；向下时肩膀略张开，向上时略收、背部伸直。
- 前后倾单独制作。

参考：[CGBox](https://cgbox.jp/2020/05/12/live2d-body-xyz/)、[palkaloid](https://palkaloid.com/588/set-xy-body/)、[伊糖だねこ](https://note.com/itodaneko/n/ndbaa6da2927f)、[Live2D Cubism Cookbook](https://ruolinzheng.gitbook.io/live2d-cubism-cookbook/modeling-and-rigging/deformer-hierarchy)。

现在身体由 `BodyStance` 建模，层级重建为：

```
DeformBodyXY（根，身体 X × 身体 Y：躯干转向、肩部变化，身体随髋部横移、下沉、站高；腿部姿势的髋部运动）
 └ DeformBodyLean（身体前后倾 × 大小变）
     └ DeformBodyZBreath（身体 Z、呼吸，第三阶段）
         ├ DeformSkelTorso（有骨架时）→ 躯干、裙子、手臂、尾巴、头部
         └ DeformArmHang_L/R（无骨架时，经由成对 warp）→ 手臂
DeformLegs（根，腿部 × 大小变：两骨 IK 弯曲，脚固定）
 ├ 未绑定的腿、鞋网格
 └ 腿骨旋转变形器
     └ DeformSkel_<骨骼 ID>Stance（绑定了网格的腿骨才有）→ 绑定的腿部网格
```

- **范围**：`DeformBodyXY` 只覆盖挂在呼吸 warp 下的部件（躯干、衣服、手臂、裙子、尾巴）、躯干和头部转动的脖子。头部旋转只传支点，所以头和头发不需要在范围内；腿在 `DeformLegs` 中。
- **站立模型**：
  - 髋、膝、踝取自腿骨；没有骨架时从腿、鞋图层估计：两腿分图层时各取一侧，合在一张图层时取左右四分之一处，踝在鞋口。
  - 没有腿图层、或腿到不了髋线以下一个躯干长度时视为半身，没有 `DeformLegs`，身体不随髋移动。
- **身体 X**（±10）：
  - 躯干是横截面为椭圆的实体（深度为宽度的 0.7，到脖子收窄到 0.15），绕中线转 12°，从头部上方的视点按透视看。
  - 胸前向转向一侧移动，转向前方的一侧略大略低，另一侧略小。脖子靠近转轴、几乎不动，所以头始终在身体中间。
  - 转角从腰部的 0 增加到腰上方 0.6 个躯干长度处的全角度。躯干两侧以外的点随轮廓整体移动，手臂留在肩上。
  - 整个身体随髋部横移 2.5% 腿长，不倾斜；腿伸不到原画的直度时，髋部自动下沉到双脚都够得着。
- **身体 Y**：
  - 负方向整个身体随髋部下沉 3.5% 腿长，膝盖内转 45°；肩膀张开 2%，背部缩短 1.5%。
  - 正方向腿伸直（已直时整体拉伸），髋部上升 1.2% 腿长，脚不动；肩膀收拢 1.5%，背部伸长 1.5%。
  - 不再踮脚。
- **身体前后倾**（新参数 `ParamBodyLean`，±10，正值前倾）：
  - 按三维实体前倾再透视绘制：躯干截面为椭圆（厚度为宽度的 0.7，到脖子变薄）。满值前倾 28°、后仰 12°，骨盆绕髋关节承担 30% 并带动裙子。
  - 脊柱在腰部上下各 0.6 个躯干长度内沿弧线从骨盆的角度逐渐弯到全角度，弯曲轴在躯干前后中点往前一半处。原来上身在腰部按两段刚体旋转的位置混合，腰部弯折处的胸前被压得比整体多（局部只剩 0.69）；现在从腰到肩各段的缩短在 0.81–0.88 之间。
  - 镜头在正前方 9 个躯干长度、肩上 0.5 个躯干长度，比身体 X 的镜头远，让前倾主要表现为胸部透视缩短和下移，而不是变大（满值时肩部下移约 12% 躯干长度，头放大约 6%）。后仰时肩部位置基本不变，整体变小。
  - 脖子以上的头不随胸部缩短，按脖子处的位置和比例整体移动、缩放，保持原有形状。
  - 面部配合：头部所有以角度 Y 为轴的 warp（头壳、面部九姿态、五官、耳、前后发跟随）另加前后倾轴（3 键），前倾满值时取角度 Y 下移 12 处的形状，后仰满值时取上移 8 处的形状，按原有关键形线性插值、超出范围时取端点。
  - 手臂：未启用骨架时每只手臂另有 `DeformArmHang_L/R`（3×6，前后倾 × 大小变各 3 键），挂在原来的父级下，控制点按父级在各键值上的实际求值反算，使手臂像从肩膀垂下的整体一样随肩膀移动和缩放。骨架的手臂旋转变形器按所在高度缩放。
  - 之前几版的问题：最早按高度线性压扁再放大，宽高比变了，只是怪异地变大；之后改成上身整体下移，但腰以下和与裙子重叠的手臂不动，看起来像纸片对折，没有立体感；再之后镜头近、角度小，放大比下移明显，看起来是头身比在变而不是前倾。这一效果另作为“大小变”参数保留。
- **大小变**（新参数 `ParamProportion`，±10，正值更接近 Q 版），与前后倾共用 `DeformBodyLean`，先按头身比变形再前倾：
  - 正值时头从脖子处整体放大 15%，胸部宽度从腰到肩逐渐增加到 8%，躯干高度缩短 6%，手臂相对肩部缩小 6%；负值相反。
  - 踝以上到腰之间（腿和裙子）缩短 10%，腰以上随之整体下移；`DeformLegs` 和绑定网格的腿骨站姿 warp 也加大小变轴（3 键），脚不动。没有腿的角色下身不变。
  - 头仍落在肩上。
  - 预设动作和跟踪不驱动它。
  - 腰以下不动。
  - 预设跟踪不驱动它。
- **腿**：多出的弯曲朝观众方向，从正面看大腿变短而不是向外甩。腿与髋部、大腿与小腿、小腿与脚之间各有过渡带，两条腿之间按两腿中线平滑过渡，所以一张图层上的两条腿也能各自屈膝。
- **缩放**：warp 的缩放传不到旋转变形器，所以头部旋转和直接挂在身体上的手臂、翅膀旋转变形器各加前后倾和大小变两个轴（各 3 个键），按所在高度缩放；大小变时头以下的骨骼按手臂的比例缩放。
- **腿部姿势**：
  - 下蹲（下沉 10% 腿长，原 6%）、重心、膝盖内扣、弹起，改为身体和腿部 warp 上的融合变形，腿骨不需要绑定网格，`tml`、`ds` 上都可用。
  - 已绑定网格的腿骨另按 IK 转动旋转变形器，与原来一致。
- **绑定网格的腿**：旋转变形器只传递支点和角度，`DeformLegs` 的弯曲传不到挂在腿骨下的网格，原来这类模型在身体 X/Y 下整个下半身不动。现在每根挂着网格的腿骨下加一个站姿 warp（身体 X × 身体 Y，每轴 3 键）。每个键值上，先按运行时求值得到这根骨骼的实际位置，再把控制点反算到它的局部坐标，使网格落在 `DeformLegs` 给出的位置：髋部随身体移动、膝盖弯曲、脚不动。静止时是恒等映射，骨骼参数照常带着它转动。骨骼参数和身体 X/Y 同时较大时，站姿按静止的腿计算，只是近似。
- **新增关键形**：
  - `DeformBodyXY` 9 个（身体 X × 身体 Y，每轴 3 键），`DeformLegs` 27 个（另加大小变），`DeformBodyLean` 9 个（前后倾 × 大小变）。
  - 头部 13 个以角度 X × 角度 Y 为轴的 warp 各从 9 个增加到 27 个（加前后倾）。
  - 头部旋转从 3 个增加到 27 个；挂在身体上的手臂等旋转变形器，关键形数量各乘以 9。
  - 绑定网格的腿骨，每根加一个站姿 warp，27 个关键形。
  - 无骨架时每只手臂一个垂挂 warp，9 个关键形。
  - 没有新增网格关键形。
  - `DeformBodyXY` 的网格从 4×6 改为 12×14，范围也变了，旧工程对它的关键形编辑不再重放。
- **预览驱动**：
  - CPU 预览中，身体以较慢的速度追随头的目标（头先身后），身体 X/Y 的增益从 4/2 提高到 8/8。
  - SDK 预览仍使用原生的 `CubismLook` 和 `CubismBreath`。停用它们需要改原生桥接并重新编译动态库，留到后续。
- **校验**：`DeformBodyXY` 只检查是否存在。身体以躯干中线为轴按透视转向，而身体部件不一定以中线左右对称，所以不做行宽镜像检查。旋转变形器的缩放只在前后倾和大小变都为 0 的关键形上要求为 1。

### 验证

- `MotionSynthTest`：普通和 Q 版程序化人形上，所有预设动作每一帧的手臂都在舒适范围内，曲线稀疏、首尾回到静止；挥手、欢呼、害羞的手到达目标区域；跳跃起落带速度。待机循环接缝的值和斜率连续，三次呼吸深浅不同且吸气短于呼气，重心半个、三分之一个循环后不重复，头在呼吸之后点头，小臂晚于大臂摆动；IdleCute 的手臂在合拢姿势附近摆动。
- `BodyBreathWarpTest`：腰以下在任何呼吸和身体 Z 下都不动，抬升从腰到肩递增、肩以上一致，胸口对称扩张、躯干外侧整体平移；身体 Z 向上递增、左右镜像、每行一致；`tml` 的躯干定位在脸下方，身体 Z 通过行宽对称校验。
- `BodyStanceTest`：
  - 任何身体 X/Y 下整只脚不动。
  - 身体 X：整个身体水平横移 5–15px 且不倾斜，腿不被拉直；胸前转向该侧，脖子的位移不到胸前的四成，头的位移不超过髋部的 1.6 倍；转向前方的肩膀更低更宽；腰以下只随髋移动；左右镜像。
  - 身体 Y：负方向身体下沉、膝盖内移、大腿变短而宽度不变、肩膀张开；正方向腿伸直、髋上升，脚踝不动，肩膀收拢。
